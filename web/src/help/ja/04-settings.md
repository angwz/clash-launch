# コアの設定

エディターの**コアの設定**には、mihomoのオプションがセクションごとに並んでいます：一般、インバウンド、コントローラー、DNS、TUN、スニッファー、地理データなど。

## 項目カードの見方

- **タイトルとキー**：名前とYAMLのキー（例：拡張モード`enhanced-mode`）。
- **既定のオン・オフ**：設定しない場合にコアが使う値です。設定しない項目は設定ファイルに書き込みません。
- **推奨／おすすめ**：「推奨」はmihomoのドキュメントによるもの、「おすすめ」は一般的な慣習で公式の要件ではありません。クリックすると適用されます。
- **詳細とアドバイス**：概要、選び方、選択肢の違い、YAML、公式ドキュメントへのリンク。
- **リセット**：入力した値を消し、コアの既定値に戻します。

項目にマウスを乗せると、プレビューでYAMLのどこに入るかが強調表示されます。

マスタースイッチのあるセクション（DNS、TUN、スニッファー、NTPなど）がオフのときは、セクション全体を配信する設定から外します。プレビューにはコメントとして表示されるので、設定した内容は見えたままです。

## よく変更される設定

- **インバウンド → 混合ポート**：ブラウザやシステムプロキシ用のポート。一般的には7890です。
- **DNS → 有効、拡張モード**：通常はDNSを有効にし、fake-ipを使います。
- **TUN → 有効**：ゲームやCLIなど、システムプロキシに従わないアプリも経由させます。
- **インバウンド → LANからの接続を許可**：スマートフォンなどほかの端末からこのマシンを使えるようにします。パスワードか接続元の制限も設定してください。

## フォームにない設定

フォームはmihomo v1.19.33に基づいています。まだない項目は「YAMLを直接編集」で設定全体に直接書き込めます。直接編集が関わる項目には⚡の印が付きます。

すべての項目を調べるには、**事典**をセクションごとに見てください。
