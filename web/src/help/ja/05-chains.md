# プロキシチェーン

プロキシチェーンは、一部のノードを**別のノード（前段のプロキシ）を経由させて**から送ります：

この端末 → 自分のVPS → 提供元のノード → Webサイト

よくある用途：自分のネットワークから提供元に直接つながらない場合や、Webサイトから見える出口を固定したい場合。

## 設定方法

**ノードとルーティング**の下部にある**プロキシチェーン**でルールを追加します：

1. **前段のプロキシ**：ノードかプロキシグループ。
2. **対象**：サブスクリプション、地域、名前の正規表現でノードを選びます。空欄ならすべてのノードです。
3. ルールは順に適用され、後のものが前のものを上書きします。

各ルールには実際に適用されるノードが表示されます。設定ではmihomoの`dialer-proxy`を使います：

```yaml
proxies:
  - name: HK 01
    type: ss
    dialer-proxy: My VPS
```

## 注意点

- **循環は不可**：AがBを経由し、BがAを経由するのは循環です。そのようなルールは適用されず、エラーとして表示されます。
- **グループは循環しうる**：チェーンされたノードを含むグループを前段にすると警告だけが出ます。グループの現在の選択によるためです。
- **クライアントに任せるサブスクリプション**は丸ごとしか前段のプロキシを指定できず、地域や名前では選べません。
