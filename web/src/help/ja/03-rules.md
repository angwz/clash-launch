# ルーティングルール

ルーティングルールは、各接続の行き先を決めます：直接、拒否、または「プロキシ」「動画配信」「自動」などの**プロキシグループ**です。

## プリセット

「ルーティングルール」ページによく使われるルールセットが並んでいます。「推奨」の印が付いたものが既定です。プリセットは上流に追従するので、手入れは不要です。

## カスタムルール

**カスタムのルーティングルール**をクリックすると、subconverterの周辺でよく使われる形式を使えます：

- `groups.toml`：プロキシグループと、それぞれが使うノード
- `rulesets.toml`：ルールセットと、それを割り当てるグループ
- 外部設定`ini`：ACL4SSRなどが使う形式

各ファイルは**URL**（上流に追従）か**貼り付けた本文**にでき、両方ある場合は本文が優先されます。

## グループがノードを選ぶしくみ

`groups.toml`では、名前の正規表現、地域、サブスクリプションでノードを選べます。サブスクリプションで選ぶ場合はその番号（`!!GROUPID=`）を使います：サブスクリプションは設定内の順番で0から番号が付き、無効なものは飛ばします。番号が使われていると、エディターには各サブスクリプションのGROUPIDが表示されます。

## 自分のルールを足す

いくつかのルールを先頭に置きたい場合（社内ネットワークへは直接接続するなど）は、**YAMLを直接編集**を開き、`rules:`の最初の行の上に挿入します：

```yaml
rules:
  - DOMAIN-SUFFIX,intranet.example.com,DIRECT
  - …（既存のルール）
```

記録されるのは追加した行だけで、ルールが更新されても先頭に残ります。
