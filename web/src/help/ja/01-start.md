# はじめに

Clash, Launch!は、**ノード**、**ルーティングルール**、**コアの設定**を1つのmihomo（Clash Meta）の設定にまとめ、長く使える**設定リンク**から配信します。クライアントはこのリンクを購読し、ここで変更した内容は次の更新で届きます。

## 4つの概念

- **ノード**：接続に使うプロキシサーバー。提供元の**サブスクリプション**か、手動で貼り付けた共有リンクから追加します。
- **ルーティングルール**：どのサイトを直接つなぎ、どれをプロキシ経由にし、どのプロキシグループを通すかを決めます。プリセットを使うか、自分のファイルを取り込みます。
- **設定**：どのノード、どのルーティングルール、どのコアの設定を使うか。1つの設定から1つのYAMLファイルが作られます。
- **設定リンク**：クライアントが設定をダウンロードするURL。1つの設定に端末ごとの複数のリンクを作れ、それぞれ個別にリセットできます。

## 最初の手順

1. 「設定」ページで**ウィザード**をクリックし、クライアントを選びます。
2. サブスクリプションのURLを入力するか、ノードの共有リンクを貼り付けます。
3. ルーティングルールを1つ選びます。迷ったら「推奨」の印が付いたものを選んでください。
4. 設定リンクをコピーし、クライアントにサブスクリプション（または「プロファイル」）として追加します。

> 設定リンクはノードのパスワードと同じくらい重要です。漏れた場合は「設定リンク」ページで**リセット**をクリックすると、古いリンクはすぐに使えなくなります。

## 変更するには

エディターで設定を開きます：

- **ノードとルーティング**：ノードソースの追加や並べ替え、ルーティングルールの切り替え、プロキシチェーンの設定。
- **コアの設定**：DNS、TUN、インバウンドのポートなど。すべての項目に**詳細とアドバイス**があり、迷ったら提案をクリックすれば適用されます。
- プレビューには生成されるYAMLが表示され、保存のたびにmihomoのカーネル（`mihomo -t`）で自動チェックされます。結果は上部バーに表示されます。
- 保存すると、クライアントは次の更新で変更を受け取ります。
