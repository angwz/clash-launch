# 节点：订阅与手动节点

「节点」页是你的节点库。每一项要么是**订阅**，要么是**手动节点**。

## 订阅

填写机场提供的订阅地址，服务器会按设定的间隔定期拉取。支持的内容格式会自动识别：

- 每行一条的分享链接（`ss://`、`vmess://`、`vless://`、`trojan://` 等）
- base64 编码的订阅
- Clash / mihomo YAML
- sing-box JSON

拉取失败时节点页会显示失败时间，配置会继续使用上一次成功拉取的结果，并在检查结果中提示。

## 手动节点

直接粘贴一条或多条分享链接、YAML 或 JSON。适合自建服务器（VPS）或临时测试的节点。

## 整理

每个来源都可以单独整理节点名称，例如：

- 在名称前添加国旗，或替换已有的国旗
- 用正则只保留或排除部分节点
- 按规则重命名、添加前缀
- 去掉「剩余流量」「到期时间」这类信息节点，去掉重复节点

地区会根据名称中的国旗、关键字等自动识别；识别错误时可以在节点详情里手动指定。

## 在配置中选用

在编辑器的「节点与分流」里添加来源。从上到下就是节点在配置中的顺序，可以拖动调整。

每个订阅还可以选择写法：

- **写入配置**：节点直接写进 YAML 的 `proxies`，可以整理、改名、参与链式代理。
- **交给客户端**：写成 `proxy-providers`，由客户端自己拉取订阅。配置更小，但整理设置中客户端无法表达的部分不会生效（检查结果会列出）。

怎么选：想改名、加国旗、按地区分组或套链式代理，用「写入配置」；订阅节点很多、更新很频繁，或机场只允许客户端拉取时，用「交给客户端」。拿不准就用「写入配置」。

新加入的订阅使用管理员设定的默认写法。管理员与经邀请注册的用户可以逐个更改；开放注册的账号只能使用默认写法，检查结果会注明。
