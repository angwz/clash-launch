# 在客户端中使用

配置链接是一个普通的 HTTPS 地址，任何支持 mihomo（Clash Meta）配置订阅的客户端都可以使用。

## 添加订阅

1. 在配置的「配置链接」页复制链接，或用手机扫描二维码。
2. 在客户端中找到「订阅」「配置」或「Profile」，选择从 URL 导入，粘贴链接。
3. 建议在客户端中开启自动更新；这里的修改会在下次更新时生效。

## OpenClash（OpenWrt）

创建配置时选择 OpenClash 预设，生成的配置会按 OpenClash 自带的内核检查。在 OpenClash 的「配置订阅」中添加链接即可。路由器上通常建议：

- 常规 → 进程匹配模式设为 `off`（官方推荐，路由器无法识别其他设备的进程）
- 地理数据加载器保持默认的 `memconservative`，节省内存

## 一份配置，多台设备

给每台设备单独创建一条链接并写好备注（例如「手机」「路由器」）。「配置链接」页会显示每条链接最近一次被访问的时间和客户端，某台设备丢失时只重置它那条即可。
