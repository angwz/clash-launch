# 分流规则

分流规则决定每个连接去哪里：直连、拒绝，还是交给某个**策略组**（例如「节点选择」「流媒体」「自动选择」）。

## 预设

「分流规则」页列出了几套常用规则，标着「推荐」的是默认选择。预设随上游更新，不需要自己维护。

## 自定义

点击「自定义分流规则」，可以使用 subconverter 生态通用的格式：

- `groups.toml`：策略组定义，包括每个组用哪些节点
- `rulesets.toml`：规则集与它们对应的策略组
- 外部配置 `ini`：ACL4SSR 等项目使用的格式

每个文件可以填**地址**（跟随上游更新），也可以直接**粘贴文本**。两者都有时以粘贴文本为准。

## 策略组如何挑选节点

`groups.toml` 中可以按名称正则、地区或订阅挑选节点。按订阅挑选时使用订阅编号（`!!GROUPID=`）：订阅按在配置中出现的顺序从 0 开始编号，停用的不计。用到编号时，编辑器里的订阅旁会显示它的 GROUPID。

## 自己补充规则

想在规则最前面加几条（例如公司内网直连），可以在编辑器里「直接编辑 YAML」：

```yaml
rules: !prepend
  - DOMAIN-SUFFIX,intranet.example.com,DIRECT
```

`!prepend` 表示插到生成的规则之前，`!append` 表示追加到末尾。
