# 快速上手

Clash, Launch! 把你的**节点**、**分流规则**和**内核设置**组合成一份 mihomo（Clash Meta）配置，生成一条长期有效的**配置链接**。客户端订阅这条链接，以后在这里改动，客户端下次更新就会拿到新配置。

## 四个概念

- **节点**：能连出去的代理服务器。来自机场的**订阅**，或者你手动粘贴的分享链接。
- **分流规则**：决定哪些网站直连、哪些走代理、走哪个策略组。可以直接用预设，也可以导入自己的规则文件。
- **配置**：选用哪些节点、用哪套分流规则、内核怎么设置。一份配置对应一份 YAML。
- **配置链接**：客户端用来下载配置的地址。一份配置可以有多条链接，分别给不同设备，单独重置互不影响。

## 第一次使用

1. 在「配置」页点击「向导」，选择要使用的客户端。
2. 填入机场订阅地址，或粘贴节点分享链接。
3. 选择一套分流规则；不确定就选标着「推荐」的那套。
4. 复制得到的配置链接，添加到客户端的订阅（或「配置」「Profile」）里。

> 配置链接相当于你的节点密码，不要发到公开场合。泄露后到「配置链接」页点「重置」，旧链接立即失效。

## 之后怎么调整

打开一份配置进入编辑器：

- **节点与分流**：增删节点来源、调整顺序、更换分流规则、设置链式代理。
- **内核设置**：DNS、TUN、入站端口等。每项都有「说明与建议」，不确定时可以点「建议」一键采用。
- 右侧或「预览」按钮可以看到最终生成的 YAML；顶部可以运行内核检查（`mihomo -t`），确认配置能被内核正常加载。
- 保存后，客户端下次更新订阅即可生效。
