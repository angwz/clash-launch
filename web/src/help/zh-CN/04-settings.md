# 内核设置

编辑器的「内核设置」按分区列出 mihomo 的配置项：常规、入站、控制面板、DNS、TUN、域名嗅探、地理数据等。

## 读懂一张字段卡片

- **标题与键名**：中文名称和 YAML 中的键名，例如「增强模式 `enhanced-mode`」。
- **默认 开/关**：没有设置时，内核会使用这个默认值，配置里也不会写出这一项。
- **推荐 / 建议**：「推荐」来自 mihomo 官方文档；「建议」是通行做法，不是官方要求。点击即可采用。
- **说明与建议**：展开后可以看到这是什么、怎么选、各选项的区别、YAML 写法和官方文档链接。
- **恢复默认**：删除你的设置，回到内核默认值。

把鼠标停在字段上，右侧预览会高亮它在 YAML 中的位置。

## 几个最常改的设置

- **入站 → 混合端口**：浏览器和系统代理连接的端口，常用 7890。
- **DNS → 启用、增强模式**：大多数情况建议开启 DNS 并使用 fake-ip。
- **TUN → 启用**：需要让游戏、命令行等不支持系统代理的程序也走代理时开启。
- **入站 → 允许局域网**：让手机等设备通过这台电脑上网时开启，并设置密码或来源限制。

## 表单里没有的设置

字段目录按 mihomo v1.19.33 编写。还没收录的字段，或需要整段覆盖的内容，可以用「直接编辑 YAML」写入，它会在表单之后合并。被它改动过的字段会带有 ⚡ 标记。

想系统了解每个字段，可以到「百科」中按分区浏览。
