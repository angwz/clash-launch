# 链式代理

链式代理让一部分节点**先经过另一个节点（前置）**再连出去，例如：

本机 → 自建 VPS → 机场节点 → 目标网站

常见用途：机场节点不允许你所在的网络直连；或者想让目标网站看到固定的出口。

## 怎么设置

在编辑器「节点与分流」页底部的「链式代理」中添加一条规则：

1. **前置**：选择一个节点或策略组。
2. **套用到**：按订阅、地区或名称（正则）选择要经过前置的节点；都不填表示全部节点。
3. 规则按顺序套用，后面的覆盖前面的。

每条规则下方会显示实际套用到的节点。生成的配置使用 mihomo 的 `dialer-proxy` 写法：

```yaml
proxies:
  - name: 香港 01
    type: ss
    dialer-proxy: 我的 VPS
```

## 需要注意

- **不能绕回自己**：A 经过 B、B 又经过 A 会形成循环，这样的规则不会套用，并在检查结果中报错。
- **经过策略组可能形成循环**：前置选了一个包含被套用节点的策略组时，只会给出警告，因为是否循环取决于组当前选中的节点。
- **交给客户端的订阅**只能整体设置前置，不能按地区或名称挑选其中一部分。
