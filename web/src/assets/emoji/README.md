# Fluent Emoji Flat

| warning.svg | ⚠️ U+26A0 | 警告 |
| thinking.svg | 🤔 U+1F914 | 不建议 |
| cross.svg | ❌ U+274C | 失败 |
| mailbox.svg | 📭 U+1F4ED | 空状态 |
