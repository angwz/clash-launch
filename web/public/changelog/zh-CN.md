## 1.1.0 · 2026-11-23

### 账号与安全

- 用户协议：注册时阅读并同意，协议更新后先同意再继续使用。
- 两步验证策略：管理员可以要求管理员或全部用户启用。
- 个人访问令牌：脚本可以只读或读写自己的配置，不能接管账号。
- 个人备份与还原：下载口令加密的全部信息，还原前自动留底 7 天。
- 注销账户：7 天冷静期内登录即撤销。
- 头像与默认昵称：注册时随机分配一个启动主题的头像和昵称，可以换，也可以上传图片。
- 站内消息端到端加密：文字在浏览器里加密，服务器只保存密文。

### 配置与节点

- 导入网上复制的 Clash 或 mihomo 配置；导出与订阅相同的 YAML，可以去掉节点或规则集再分享。
- 删除保护、删除后 10 秒内可撤销、多选批量操作。
- 规则源编辑器：toml 与 ini 高亮，行内显示问题，并预览展开后的策略组。
- 节点内容即时预览，恢复默认可以撤销。
- 节点内容的大编辑框：按协议提示字段与取值，右侧有缩略图，逐个用 mihomo 校验，有问题时不能完成。
- 规则源的策略组可以点选地区、节点源、协议与标签作为选择条件。
- 删除收进「⋯」菜单，不再一点就删。

### 订阅与提醒

- 订阅链接访问限制：限定客户端、国家或地区与每天拉取次数。
- 站内提醒：节点源连续拉取失败、后台检查不通过、订阅出现新的国家或客户端。
- 提醒除邮件外还可以发到 Webhook、Telegram、Bark 与 ntfy。
- 订阅分析可以导出为 CSV。

### 界面

- 实时更新：数据变化即时出现，联系人显示在线状态。
- 左下角的在线指示灯：断线、未读、工作中、新版本各有表现。
- 命令面板（Ctrl K）能搜到自己的配置、节点名、短链接与联系人；按 ? 查看全部快捷键。
- 浏览器返回回到刚才的位置；未保存时离开会先确认。
- 足迹：永久记下第一次、里程碑与新地区。
- 强调色可以在设置里更换；可以把网站添加到主屏幕。
- 站内公告、不用注册的试用页、日语界面（含字段说明与诊断消息）。
- 订阅分析与登录设备的地区名跟随界面语言；用 http 访问时复制按钮也能用。

### 运维

- 默认使用 PostgreSQL，compose.yaml 自带；旧版的 SQLite 数据照常可用，并提示一条命令迁移（见部署文档）。
- 内核与字段目录跟进 mihomo v1.19.34：Snell v6、Shadowsocks 入站多用户等。
- 最简 docker compose，镜像启动后自动降权，支持 PUID 与 PGID；加固改为叠加文件。
- /metrics 输出 Prometheus 指标；管理页显示后台任务与数据量，可以在网页上调整保留期。
- PostgreSQL 的连接池与语句超时可配置。
